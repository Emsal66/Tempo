<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Releases (internet) → updater | Downloaded installer and latest.json |
| GitHub Actions secrets → release job | Private signing key usage |
| Tag push → release pipeline | Who can create releases |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-15-01 | Tampering | Malicious/MITM update | mitigate | Mandatory minisign verification with committed pubkey (plugin cannot disable it); HTTPS endpoint; config gate asserts pubkey == committed file |
| T-01-15-02 | Information Disclosure | Signing key exposure in CI | mitigate | Secrets referenced only in tag-triggered `release.yml` job; `ci.yml` gate forbids `secrets.`; actions SHA-pinned; key generated offline by owner (plan 01-04) |
| T-01-15-03 | Elevation of Privilege | Silent or remote-triggered install | mitigate | Install only via user action (tray item, command, or act/update link with single-use token); no `updater:*` webview permission (D-02) |
| T-01-15-04 | Tampering | Wrong version released | mitigate | `--check-tag` makes the release job fail unless tag == v + Cargo version; drafts published manually after install check |
| T-01-15-05 | Denial of Service / Integrity | DB corruption on update exit | mitigate | `on_before_exit` closes the pool with WAL checkpoint and flushes logs before `process::exit` |
| T-01-15-06 | Repudiation | Which build users run | mitigate | Version visible on Durum and Güncellemeler; release names `Mornfold vX.Y.Z` |
</threat_model>
