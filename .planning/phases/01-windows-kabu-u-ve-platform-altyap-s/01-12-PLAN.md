| Shell → Windows Credential Manager | Master key storage |
| Process → log files | Everything logged lands on disk |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-12-01 | Information Disclosure | Secret read-back via IPC/DevTools | mitigate | No command returns values; `get_for_connector` never called from shell (grep gate); bindings contract test |
| T-01-12-02 | Information Disclosure | Secrets in logs | mitigate | Redacting `format_line` on every log record; values never logged (only names/ids); tests `logging_*`; core canary test |
| T-01-12-03 | Information Disclosure | Secret in UI memory/storage | mitigate | Value only in component state, cleared after submit/cancel/unmount; never in React Query/zustand/localStorage (test `keys_value_never_cached`, grep gate) |
| T-01-12-04 | Information Disclosure | Roaming credential | mitigate | `persistence=Local`; fixed service/user names without "." |
| T-01-12-05 | Denial of Service | Credential Manager unavailable / key lost | mitigate | App still starts; Turkish banner; explicit user-confirmed reset; never silent regeneration |
| T-01-12-06 | Tampering | Oversized or malformed name/value | mitigate | Client-side and core validation (64 chars / 8192 bytes, no control chars) |
