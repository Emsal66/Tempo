## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-16-01 | Tampering | Malicious/MITM update | mitigate | Mandatory minisign verification with committed pubkey (plugin cannot disable it); HTTPS endpoint; config gate asserts pubkey == committed file |
| T-01-16-02 | Information Disclosure | Signing key exposure in CI | mitigate | Secrets referenced only in tag-triggered `release.yml` job; `ci.yml` gate forbids `secrets.`; actions SHA-pinned; key generated offline by owner (plan 01-04) |
| T-01-16-03 | Elevation of Privilege | Silent or remote-triggered install | mitigate | Install only via user action (tray item, command, or act/update link with single-use token); no `updater:*` webview permission (D-02) |
| T-01-16-04 | Tampering | Wrong version released | mitigate | `--check-tag` makes the release job fail unless tag == v + Cargo version; drafts published manually after install check |
| T-01-16-05 | Denial of Service / Integrity | DB corruption on update exit | mitigate | `on_before_exit` runs `shutdown_blocking` (WAL checkpoint on a fresh thread, bounded wait) and flushes logs before `process::exit` |
| T-01-16-06 | Denial of Service | runtime-within-runtime panic on install | mitigate | `install_ready` is async; `Update::install` dispatched with `run_on_main_thread`; grep gate forbids `block_on` in updater/tray/deeplink/update command files |
| T-01-16-07 | Repudiation | Which build users run | mitigate | Version visible on Durum and Güncellemeler (plan 01-17); release names `Mornfold vX.Y.Z` |
</threat_model>
