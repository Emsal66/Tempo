<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Any web page / local process → `mornfold://` handler | Untrusted URL reaches the app via protocol activation or single-instance argv |
| Future remote text (mail subjects, monitor titles) → toast XML | Untrusted text rendered by Windows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07-01 | Tampering / Elevation | `mornfold://act/*` from a web page or argv | mitigate | Allowlist parser + action requires an unconsumed, <7-day notification id consumed atomically (tests `notifications_token_*`, `deeplink_rejects`) |
| T-01-07-02 | Tampering / Spoofing | Toast XML injection | mitigate | quick-xml writer escaping, control-char stripping, truncation; adversarial test counts `<action ` elements |
| T-01-07-03 | Denial of Service | Oversized URL / query | mitigate | 512-byte cap checked before parsing; duplicate/unknown keys rejected |
| T-01-07-04 | Repudiation | Replayed action click | mitigate | `consumed_at` recorded; second use returns AlreadyUsed |
| T-01-07-05 | Information Disclosure | Notification rows | accept | Title/body are non-secret UI text stored locally in `%LOCALAPPDATA%` |
</threat_model>
