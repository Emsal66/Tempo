Create `.github/workflows/ci.yml` named `CI`:
- Triggers: `on.push` with BOTH `branches: ['**']` AND `tags-ignore: ['v*']` (GitHub treats a push filter that lists only `tags-ignore` as tag-only, so branch pushes would not run CI without the explicit `branches` key; tags are handled by the release workflow in plan 01-16) and `pull_request` (never `pull_request_target`). `permissions: contents: read`. `concurrency: { group: ci-${{ github.ref }}, cancel-in-progress: true }`. `env: { CARGO_TERM_COLOR: always, RUST_BACKTRACE: 1 }`.
- Pin every third-party action by full commit SHA with a trailing `# vX.Y.Z` comment. Resolve SHAs from the container with `gh api repos/<owner>/<repo>/commits/<tag> --jq .sha` for: actions/checkout (latest v4/v5 tag), pnpm/action-setup (v4), actions/setup-node (latest major), Swatinem/rust-cache (v2), actions/upload-artifact (v4). Install Rust with plain `rustup toolchain install 1.99.1 --profile minimal --component clippy,rustfmt --target x86_64-pc-windows-msvc` (no third-party toolchain action needed).
- Job `linux` (`runs-on: ubuntu-24.04`, `timeout-minutes: 60`): checkout → apt-get install the Linux deps listed in interfaces → rustup step → rust-cache → pnpm/action-setup (reads packageManager) → setup-node `node-version: 24` with `cache: pnpm` → `pnpm install --frozen-lockfile` → `pnpm -C ui build` → `cargo fmt --all --check` → `cargo clippy --workspace --all-targets -- -D warnings` → `cargo test --workspace` → bindings drift: `cargo test -p mornfold-app --test bindings && git diff --exit-code ui/src/bindings.ts` → `cargo install --locked cargo-xwin --version 0.23.1` (skip if cached binary exists) → `cargo xwin check --target x86_64-pc-windows-msvc -p mornfold-app` → `pnpm -C ui exec biome ci .` → `pnpm -C ui exec tsc --noEmit` → `pnpm -C ui exec vitest run`.
- Job `windows` (`runs-on: windows-2025` — pinned, not windows-latest; `timeout-minutes: 75`; `defaults.run.shell: pwsh`): checkout → rustup step → rust-cache → pnpm/action-setup → setup-node 24 with pnpm cache → `pnpm install --frozen-lockfile` → `pnpm -C ui build` → `cargo test --workspace` (runs cfg(windows) tests) → `pnpm tauri build --bundles nsis` (no TAURI_SIGNING_* env; `createUpdaterArtifacts` is false in the base config) → startup smoke step: start `target\release\Mornfold.exe --minimized` with `Start-Process -PassThru`, wait 20 s, fail if `$p.HasExited` is true, then if `$env:LOCALAPPDATA\com.mornfold.desktop\logs\mornfold.log` exists print its last 50 lines and require it to contain "başlatıldı", finally `Stop-Process -Id $p.Id -Force` → `actions/upload-artifact` with `name: mornfold-nsis-${{ github.sha }}`, `path: target/release/bundle/nsis/*.exe`, `if-no-files-found: error`, `retention-days: 14`.
- No `secrets.` reference anywhere in this file.

Create `scripts/ci-wait.sh` (bash, `set -euo pipefail`, executable) — the Windows gate used as the final `<automated>` verify of plans 01-10, 01-12..01-17 (and the pre-tag gate in 01-18 and 01-19): (1) if `git status --porcelain --untracked-files=no` is non-empty, print "önce commit edin: CI kapısı yalnızca commit edilmiş HEAD'i test eder" and exit 3 (the executor commits the task first, then runs the gate); (2) `git push origin HEAD` (retry up to 4 times with 2/4/8/16 s backoff on network errors); (3) SHA = `git rev-parse HEAD`; poll `gh api repos/Emsal66/Tempo/commits/$SHA/check-runs --jq '.check_runs[] | [.id, .name, .status, .conclusion] | @tsv'` every 60 s for up to `${CI_WAIT_MINUTES:-75}` minutes until both `linux` and `windows` are `completed`; (4) if a run concluded `cancelled` (the `concurrency: cancel-in-progress` group was superseded by a newer push from a parallel plan), `git fetch origin` and, when the remote branch head is a descendant of SHA (`git merge-base --is-ancestor`), switch SHA to that head and keep polling; (5) exit 0 only when both are `success`; on `failure`, print each failing check-run's `output.title`, `output.summary` and its annotations (`gh api repos/Emsal66/Tempo/check-runs/<id>/annotations`) and exit 1; on timeout exit 2. The `/actions/*` endpoints are blocked by the container proxy, so the script uses only check-runs and annotations. It never prints tokens or environment variables.
