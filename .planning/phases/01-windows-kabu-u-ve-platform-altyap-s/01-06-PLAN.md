|----------|-------------|
| Vault ↔ KeyProvider (Credential Manager) | Master key crosses from OS store into process memory |
| Vault ↔ SQLite file | Only ciphertext + metadata at rest |
| Vault → logs / Debug / serde | Potential accidental disclosure path |
