## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Second process argv → single-instance channel | Any local process can launch Mornfold with arbitrary args |
| WebView2 (UI) → Rust commands | UI is the least-trusted tier with IPC |
| Remote origins → IPC | Must have no IPC access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-09-01 | Tampering | argv in single-instance callback / startup | mitigate | `StartupArgs::parse` allowlists `--minimized` and a length-capped `mornfold://` string, ignores all else; never passed to a shell (tests `startup_args_*`); URL validated by core deeplink parser in plan 01-14 |
| T-01-09-02 | Elevation of Privilege | Webview capabilities | mitigate | Capability grants only event listen + window-chrome permissions; no plugin permissions; acceptance criterion greps for plugin prefixes |
| T-01-09-03 | Tampering / XSS | Webview content | mitigate | Strict CSP (`script-src 'self'`, `object-src 'none'`, `frame-ancestors 'none'`), `freezePrototype`, no remote URLs |
