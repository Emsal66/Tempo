# Phase 1 Plan 03: Decision records, smoke checklist and brand assets Summary

The distribution decision (NSIS + GitHub Releases + signed updater, D-01) and the Phase 1 platform defaults are now written as Turkish ADRs, alongside a Turkish S-0..S-11 smoke checklist for the owner's Win11 PC. The plan also adds an original synthesized notification ping and a deterministic set of app/tray/SVG mark assets, all generated by stdlib-only Python scripts.

## What was built

### Task 1: Decision records (commit a288ffb)
- `docs/decisions/0001-distribution-channel.md` covers:
  - D-01 channel: NSIS `currentUser` with a Turkish installer, plus GitHub Releases and `tauri-plugin-updater`. MSIX is revisited in v2.
  - D-03: releases are published in `Emsal66/Tempo`. The `latest/download/latest.json` endpoint uses draft-first releases.
  - D-04: push artifacts are built separately from tag releases. `tauri.release.conf.json` is used only in the tag job.
  - D-05: minisign key custody. Three backups, what happens if the key is lost, and how rotation works. The ADR does not contain key material.
  - The frozen identifiers.
  - Unsigned v1 together with the Smart App Control caveat (S-0).
  - The Cargo.toml version source of truth with a tag check.
- `docs/decisions/0002-phase1-platform-defaults.md` covers:
  - "Yarına kadar" means the next local midnight.
  - Toast activation tiers built on `mornfold://`.
  - Sound strategies A/B (`PlaySoundW` + `SHQueryUserNotificationState`), plus where the sound comes from (`gen-ping.py`).
  - The tray badge design.
  - Scheduler jobs `heartbeat`, `demo_check` and `update_check`.
  - Runtime-checked SQL with a concrete revisit trigger.
  - The D-17 `ProviderTester` endpoint table, `detect_provider`/`NotTestable`, and `secrets_test_saved`.
  - The accepted DPAPI risk.

### Task 2: Smoke checklist (commit 5feb4d5)
- `docs/smoke-test-phase1.md` is written fully in Turkish and contains:
  - An empty "Test edilen sürüm" section for plan 01-18 to fill.

### Task 3: Original sound and icon/logo assets (commit b0c32c2)
- `scripts/gen-ping.py`:
  - Synthesizes C6 + G6 + C7 decaying sine partials. A 4 ms attack, a +1.5% glide over 60 ms on partial 1, and a 20 ms cosine fade-out.
  - Output is 44.1 kHz mono 16-bit, 0.45 s long, with peak 0.700.
  - `--check` validates PCM / 16-bit / mono / 44100 Hz / duration < 1 s / peak <= 0.75.
  - The header comment states that the sound is an original synthesis (D-09).
- `scripts/gen-icons.py`:
  - An SDF rasterizer with 4×4 supersampling on edge pixels, and a PNG RGBA writer (zlib level 9, `zlib.crc32`).
  - Mark: a half sun above a chevron "fold" line, round caps and a round outer join.
  - App icon: 1024×1024 rounded square with a 22% corner radius and a #1B1A3A→#4C3BCF gradient. The white mark is 56% of the canvas width.
  - Tray icons are 32×32: white for dark taskbars, #1F1F1F for light taskbars.
    - unread: #8B7CFF dot with radius 5.
    - paused: 40% alpha.
    - error: #EF4444 dot.
  - The SVG mark (viewBox 0 0 64 64, `fill="currentColor"`) is generated from the same geometry as filled outline paths.
- Two runs produce byte-identical output for the WAV, all PNGs and the SVG. `git diff --exit-code -- src-tauri/icons ui/src/assets` is clean after re-running.

## Deviations from Plan

### Minor design choices (within Claude's discretion)

**1. The error variant also gets the 1.5 px transparent ring**
- The plan specifies the ring only for `unread.png`. I applied it to the red error dot as well, so both badges separate cleanly from the mark and look the same.
- Files: scripts/gen-icons.py, src-tauri/icons/tray/*/error.png
- Commit: b0c32c2

**2. gen-icons.py also writes the SVG**
- `ui/src/assets/mornfold-mark.svg` is produced by `gen-icons.py` from the same geometry the PNGs use, rather than written by hand. This keeps the vector and raster marks the same.
- Commit: b0c32c2

**3. Smoke S-6(c2) steps made concrete**
- "Send a test toast while the window is hidden" had no defined trigger. The steps now say:
  1. Lift the mute from (c).
  2. Press "Test bildirimi gönder".
  3. Hide the window with X right away.
- This matches plans 01-14/01-15: unread clears when the window is shown or Bildirimler is opened, and is set when a toast is sent.
- Commit: 5feb4d5

Otherwise the plan was executed as written.
