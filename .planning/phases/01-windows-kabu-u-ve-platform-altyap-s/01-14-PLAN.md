## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Web pages / local processes → mornfold:// protocol handler | Untrusted URLs can launch or reach the app |
| Core XML → WinRT XmlDocument | Rendered by the OS shell |
| Sound file path → PlaySoundW | Filesystem path from bundle resources |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-14-01 | Elevation of Privilege | `mornfold://act/*` from browser/Win+R | mitigate | Core parse + atomic single-use token (<7 days) before any action; refused links only logged (smoke S-6d) |
| T-01-14-02 | Tampering | Toast XML injection | mitigate | XML built only by core quick-xml builder; Windows CI test loads adversarial XML and counts exactly 2 actions |
| T-01-14-03 | Spoofing | Wrong toast identity (PowerShell / missing) | mitigate | AUMID = identifier for installed builds; PowerShell AUMID only under target\ (Pitfall 1); smoke S-6 checks header |
| T-01-14-04 | Tampering | Incoming URL reaching a shell | mitigate | URLs never passed to Command/ShellExecute/opener (grep gate) |
| T-01-14-05 | Denial of Service | Sound during Do Not Disturb (strategy B) | mitigate | Plays only if toasts enabled and SHQueryUserNotificationState accepts; user toggle authoritative (A3 noted) |
| T-01-14-06 | Information Disclosure | Notification text | accept | Phase 1 toasts contain only static app text |
| T-01-14-07 | Denial of Service | Runtime panic from blocking inside async URL handling | mitigate | `handle_url` is async end to end; grep gate forbids `block_on` in deeplink.rs |
</threat_model>
