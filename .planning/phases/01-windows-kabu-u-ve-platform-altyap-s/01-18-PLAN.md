| Draft release → public | Publishing exposes the installer and latest.json |

| T-01-18-02 | Information Disclosure | Signing key handling during release | mitigate | Executor never touches key material; failures about secrets are escalated to the owner |
| T-01-18-03 | Repudiation | Smoke results | mitigate | Owner's table recorded verbatim with date, artifact SHA and installer source in the repo |
| T-01-18-04 | Elevation of Privilege | Act link from browser (S-6d) | mitigate | Verified manually; failure is a blocking gap |
| T-01-18-05 | Tampering | Artifact from a different commit than the release | mitigate | Doc records the tagged SHA and artifact name; Task 1 verify checks the windows check-run on `git rev-list -n 1 v0.1.0` |
